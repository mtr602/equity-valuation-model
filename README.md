Apple Equity Valuation Model (DCF)

This project builds a full discounted cash flow (DCF) valuation model in R for Apple Inc.
The model integrates financial and market data from multiple sources, performs
data cleaning and transformation, and estimates intrinsic equity value using
corporate finance valuation methodologies.

Project components:
- Financial statement and market data collection through APIs
- Automated data integration and preprocessing pipeline
- Data cleaning, validation, and transformation workflow
- Beta estimation for cost of equity
- Capital structure and WACC estimation
- Free Cash Flow (FCF) forecasting
- Discounted Cash Flow (DCF) valuation
- Sensitivity and scenario analysis
- Relative valuation using market multiples

Key Features:
- API-driven financial data retrieval
- Structured ETL-style data pipeline in R
- Automated handling of missing and inconsistent financial data
- Reproducible valuation workflow for scalable analysis
- Multi-scenario valuation framework (Base, Bull, Bear)
- Integrated quantitative finance and data analytics approach

Tools & Libraries:
- R
- tidyverse
- quantmod
- tidyquant
- dplyr

Goal:
Build a professional-grade equity valuation and financial analytics framework
that combines financial modeling, API integration, and data engineering concepts
used in real-world equity research and investment analysis workflows.
